# hukuk-dili-site

**Hukuk Dili** iOS uygulamasının pazarlama + gizlilik + destek sayfaları
(GitHub Pages: `main` dalı, kök dizin).

- `index.html` — pazarlama sayfası
- `privacy.html` — gizlilik politikası (App Store zorunlu)
- `support.html` — destek & SSS (App Store zorunlu)
- `style.css` — uygulamanın krem + bordo temasını yansıtır
- `.nojekyll` — Jekyll işlemesini kapatır

Uygulama reposu ayrı ve private'tır; bu repo yalnızca statik sayfaları barındırır.
Sayfa metinleri uygulamadaki gerçeklerle eşleşmelidir (ücretsiz: günde 1 kart +
widget + hatırlatıcı; Pro: günde 10'a kadar, arşiv, favoriler/koleksiyonlar,
test & eşleştirme).
